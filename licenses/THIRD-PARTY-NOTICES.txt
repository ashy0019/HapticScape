HapticScape Third-Party Notices
==============================

This file describes the third-party software included in the HapticScape
Windows client built against RuneLite 1.12.37. The build also extracts every
license, notice, copying, and copyright file embedded in the resolved runtime
JARs before those JARs are combined. Those exact files and the resolved
dependency inventory are placed in:

    licenses/resolved-artifacts/

The source repository for HapticScape is available at:

    https://github.com/ashy0019/HapticScape
